Diese Seite enthält die wesentlichen Befehle um mit Quartz und Obsidian über GitHub arbeiten zu können.
## Quartz 4.0
[Dokumentation (EN)](https://quartz.jzhao.xyz)

| Funktion              | Befehl                     |
| --------------------- | -------------------------- |
| Sync Data with GitHub | `npx quartz sync`          |
| Host local            | `npx quartz build --serve` |
*Für die Befehle muss der `quartz` Ordner aktiviert sein! Nutze `cd quartz`.*
